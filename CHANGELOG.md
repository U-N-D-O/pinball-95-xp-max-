# Changelog

## 0.1.0 — First playable build

Pinball Neo 95 is a portrait-first dog-park pinball game with a deliberately chunky 1995 PC-pinball look.

### Included

- Physics-driven tennis ball, flippers, launcher, walls, drain, bumpers, targets, ramps, toys, hydrant, water bowl, doghouse, and paw mission.
- Three-ball rules, ball-save bonus, score milestones, achievements, high-score persistence, game-over restart, pause, and restart flows.
- Crisp pixel-art table sprites with nearest-neighbor rendering and mobile texture budgets.
- Generated 8-bit arcade sound effects with mute and volume controls.
- Optional mobile haptics with a persistent settings toggle.
- Portrait-safe layouts, lifecycle pausing, Android/iOS/Windows identity metadata, and release builds.

### Known release prerequisites

- Physical Android and iOS device QA has not been completed in this Windows-only environment.
- Production Android/iOS signing credentials are not configured.
- Final asset-terms review, dependency license archive, and store screenshots remain pending.
