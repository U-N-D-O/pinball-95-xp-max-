# Pinball Neo 95 Privacy Policy

**Effective date:** September 16, 2026

This policy describes the behavior of the current Pinball Neo 95 build. It must be reviewed again if online services, advertising, crash reporting, accounts, or third-party store SDKs are added.

## Information the game stores

The game stores these values locally on the device using the platform preferences system:

- High score
- Sound mute setting
- Sound volume setting

These values are used only to restore the local game experience. The game does not require an account or a name, email address, location, contacts, photos, microphone, camera, or device identifiers.

## Gameplay telemetry

The current telemetry object records temporary in-memory gameplay events such as scores, drains, restarts, and achievements. It is used for local testing and performance review and is not uploaded by the game.

## Network and sharing

Based on the current application code, Pinball Neo 95 does not send gameplay data to a server, display targeted advertising, or share information with third parties.

## Deleting local data

The saved high score and sound settings can be removed by clearing the application's storage or uninstalling the game through the device operating system.

## Contact and future changes

If online features or analytics are added, this policy must be updated before release to describe what is collected, why it is collected, how long it is retained, and how players can request deletion.
